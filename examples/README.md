# Examples

Small apps that use Posterna, one folder each. They are private workspace packages: never published, used as starting points and for end-to-end tests against a mock ingest server (`docs/SPEC.md` section 11).

Planned:

- `express`: an Express app with `app.use(posterna(options))`
- `next`: a Next.js app with the `proxy.ts` integration

Every example starts in monitor mode, like every real install.
