# posterna

**Pre-release, not yet published.** The commands below are coming soon.

The [Posterna](https://posterna.com) command line.

| Command | What it does |
|---|---|
| `posterna init` | Detect Express or Next.js, write `agents.yaml` in monitor mode, and print the code to add |
| `posterna doctor --url <site>` | Check client IP resolution, the signed host and signature headers on a deployed site |
| `posterna robots` | Print robots.txt and Content Signals from `agents.yaml` |
| `posterna policy check` | Validate `agents.yaml` with clear errors |

See the [specification](https://github.com/posternahq/posterna/blob/main/docs/SPEC.md). MIT licensed.
