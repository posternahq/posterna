# Operator directory snapshot

`directory.json` and `keys.json` are a snapshot of the Posterna operator
directory, version 2026-10-28, copied unchanged from `packages/directory/data`
in https://github.com/posternahq/posterna. The plugin reads them when no newer
signed copy has been downloaded (downloads are off unless an administrator
turns them on).
